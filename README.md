# Mo' Creatures Adventure — modpack (Forge 1.20.1)

Modpack pour rejoindre le serveur **`dedication-radiation.tun.ply.gg`**.

## Option 1 — Installateur en un clic (launcher Minecraft officiel)

1. Télécharge **[Installer-Mo-Creatures.bat](https://github.com/nini17800/mo-creatures-adventure-modpack/releases/latest/download/Installer-Mo-Creatures.bat)** et double-clique dessus (si Windows affiche « Windows a protégé votre ordinateur » : *Informations complémentaires* → *Exécuter quand même*).
2. Il télécharge les mods depuis CurseForge dans `%APPDATA%\.minecraft\mods` (tes anciens mods sont mis de côté dans `mods_sauvegarde_...`), les shaders, les packs de textures et les configs.
3. Quand la fenêtre Forge s'ouvre : laisse **Install client** coché et clique **OK**.
4. Dans le launcher Minecraft : profil **forge (1.20.1-forge-47.4.0)**, mets **au moins 8 Go de RAM** (*Installations → Modifier → Plus d'options* → remplace `-Xmx2G` par `-Xmx8G`).
5. Multijoueur → Ajouter un serveur → `dedication-radiation.tun.ply.gg`.

En cas d'échec d'un fichier, relance l'installateur : il reprend où il s'était arrêté.

## Option 2 — Launcher CurseForge

1. Télécharge **[Mo-Creatures-Adventure.zip](https://github.com/nini17800/mo-creatures-adventure-modpack/releases/latest/download/Mo-Creatures-Adventure.zip)**.
2. CurseForge → Minecraft → **Create Custom Profile** → *or import a previously created profile* → **Import** → choisis le zip.
3. Lance le profil et rejoins le serveur.

## Notes

- Les textures et shaders sont installés mais pas activés : active-les dans *Options → Packs de ressources* / *Options vidéo → Shaders*.
- Les jars ne sont pas hébergés ici : tout est téléchargé directement depuis CurseForge.
- *Macaw's Regions Unexplored* n'est pas inclus (le fichier a été supprimé de CurseForge, et il n'est pas sur le serveur non plus).
